03

How a resume gets scored

  1. i

    Normalize

    Extract text from a PDF or DOCX, detect sections, and match skill mentions against a canonical alias dictionary — so reactjs, react.js, and React all resolve to the same skill.

  2. ii

    Score

    A pure rule-based engine computes a general ATS score and, per job, a company-specific score from the recruiter's weighted skills. No AI model, no third-party API.

  3. iii

    Explain

    Every score returns a breakdown: matched skills, missing skills, formatting flags, and ranked recommendations — in plain language, on the page, in the PDF.
